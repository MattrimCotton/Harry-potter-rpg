      Amis et Rivaux

        Après chaque choix, NVDA lit le nouveau texte, puis le choix suivant. Le jeu fonctionne en mode navigation comme en mode formulaire.

        Dans une liste déroulante, choisissez avec les flèches, puis validez avec Entrée. Sur un bouton, appuyez sur Entrée.

        Raccourcis

        • F1 : traits. F2 : états. F3 : sorts. F4 : amis et rivaux. F5 : chance et expérience.
        • F8 : sauvegarder. La partie se sauvegarde aussi toute seule.
        • F9 : relire le dernier texte.
        • Échap ou Retour arrière : revenir en arrière. Échap ne marche qu'en mode navigation.

        Sur un portable, maintenez Fn pour les touches F. Le menu Outils propose les mêmes actions.
